## 二、实际技术选型

与任务说明一致：

- `LoginRequest` 使用 `boolean rememberMe`，未传字段归入未勾选分支。
- `rememberMe=true`：`expiresAt = now.plusDays(7)`。
- `rememberMe=false` 或未传：`expiresAt = now.plusHours(2)`。
- 前端使用原生 checkbox，默认 `false`，不增加其他登录字段。
- T00103 的锁定检查、失败计数和 `ACCOUNT_LOCKED` 响应未改动。

## 三、新增测试用例

1. `loginWithRememberMeStoresSevenDaySession`
   - 登录请求携带 `rememberMe: true`。
   - 断言 Session 的 `expiresAt` 约为固定签发时间 + 7 天。

2. 既有 `loginWithCorrectCredentialsReturnsTokenAndSessionRow`
   - 请求不携带 `rememberMe`。
   - 继续断言默认 Session 时长约为 2 小时。
