## 二、技术选型核对

实际实现与任务说明一致：

1. `AuthException` 携带 `String code`，服务层抛出 `USER_NOT_FOUND` 或 `INVALID_PASSWORD`。
2. `AuthController` 使用 Spring MVC 的 `@ExceptionHandler(AuthException.class)` 统一返回：

```json
{
  "error": {
    "code": "USER_NOT_FOUND",
    "message": "账号不存在"
  }
}
```

3. 两类失败均返回 HTTP 401。
4. 前端按错误码映射文案，并在表单下方的单一 `role="alert"` 区域展示。
5. 未修改 feature flag、成功登录路径、会话逻辑或 Todo 鉴权。

## 三、新增测试用例

### 后端

`AuthIntegrationTest.java` 新增：

1. `loginWithUnknownUsernameReturnsUserNotFoundCode`
   - 不存在的用户名
   - 断言 HTTP 401
   - 断言 `error.code == "USER_NOT_FOUND"`

2. `loginWithWrongPasswordReturnsInvalidPasswordCode`
   - 先插入存在用户，再提交错误密码
   - 断言 HTTP 401
   - 断言 `error.code == "INVALID_PASSWORD"`

原有成功登录、Session 创建和 flag=false 返回 404 测试继续保留。

- `USER_NOT_FOUND` 显示“账号不存在”
- `INVALID_PASSWORD` 显示“密码错误”

两类错误均通过 `role="alert"` 单一提示区域验证。
