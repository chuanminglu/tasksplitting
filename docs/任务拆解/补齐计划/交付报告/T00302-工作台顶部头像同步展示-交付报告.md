# T00302 交付报告：工作台顶部头像同步展示（AC-2）

## 1. 任务目标（对应验收标准 AC-2）

上传新头像后，Todo 工作台顶部同步展示最新头像缩略图，且**同一次会话内无需刷新页面**即反映最新头像（个人中心 → 工作台视图切换）。核心架构约束：头像 URL 是**同一个共享顶层 state**，工作台**不得各自独立发起一次"获取当前头像"的查询请求**。

## 3. 技术选型（与说明一致性核对）

- spec 要求：沿用 T00301 已确立的"头像 URL 状态提升到 `App` 顶层"架构，工作台读取顶层 state，**不新增独立"获取当前头像"API 请求**。
- 实际实现（`App.tsx`，已存在于 main）：
  - `App` 顶层持有 `avatarUrl`（`string | null`）state；
  - `ProfileView` 上传成功回调 `onAvatarUploaded={setAvatarUrl}`（直接写顶层 state）；
  - `TodoBoard` 顶部 `<img className="workboard-avatar" src={avatarUrl ?? avatarPlaceholder} alt="我的头像" />`，直接绑定同一 `avatarUrl`；
  - 前端对 `/api/avatars` 只有**一次 POST 上传**，切视图时**不发起任何 GET 查询**。
- 结论：**技术选型与 spec 完全一致**。
