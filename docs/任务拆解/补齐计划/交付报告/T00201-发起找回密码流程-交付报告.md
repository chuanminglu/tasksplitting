## 一、任务概述

按候选故事-忘记密码与头像上传 执行计划 T00201（AC-1）：新增 `POST /api/auth/forgot-password` 接口——请求体 `{"email": "..."}`；**无论邮箱是否注册一律返回 200 + 相同响应体** `{"message": "如果该邮箱已注册，验证码已发送"}`；已注册则生成 **6 位数字验证码**（`SecureRandom`，10 分钟有效期）写入 `PasswordResetCode` 表并经 `EmailSender` 发送；未注册则**什么都不做**（不抛异常、不发邮件、不建记录）。验证码只允许出现在日志与数据库，**绝不出现在 HTTP 响应体**。

**email 迁移落点说明（重点偏差澄清）**：spec 首选写法是 schema.sql 里 `ALTER TABLE ... ADD COLUMN IF NOT EXISTS email TEXT`，并明确给出兜底——"若当前 SQLite JDBC 版本不支持 `IF NOT EXISTS` 语法（参照 T00103 已踩过的坑）——改用 `PRAGMA table_info` 探测 + 条件 `ALTER TABLE`"。本实现取兜底路径且**不落 schema.sql**，因为本仓 `application.yml` 为 `spring.sql.init.mode: always`，schema.sql **每次启动都重放**，裸 `ADD COLUMN`（即便 SQLite 某些版本接受 `IF NOT EXISTS`）在第二次启动即因列已存在而失败。这与 T00103 对 `failedLoginAttempts/lockedUntil` 的处理完全一致，schema.sql 中已留注释说明原因。

## 三、技术选型与方案一致性

- **不引入真实 SMTP**：`EmailSender` 接口 + `LoggingEmailSender`（仅 `log.info`），测试用 `@MockBean` 替换验证调用参数。✅
- **`SecureRandom` 生成 6 位数字码**（`String.format("%06d", secureRandom.nextInt(1_000_000))`），非 `Math.random`/`Random`。✅
- **时间源可注入**：`ForgotPasswordService` 构造注入 `Clock`（沿用 `TasksplittingApplication` 的 Clock bean），`expiresAt = LocalDateTime.now(clock).plusMinutes(10)`。✅
- **SQLite 日期格式**：写入用 `yyyy-MM-dd HH:mm:ss`（SQLite JDBC 日期解析只认该格式，`SessionRepository`/`UserRepository` 既有约束）。✅
- **恒 200 响应**：Controller 不感知邮箱是否存在，杜绝注册状态泄漏（时序防护按 spec 明确不做）。✅

`ForgotPasswordIntegrationTest` 共 4 个用例，全部通过（独立 DB、`@MockBean EmailSender`、`TestClock` 固定时钟、播种数据直接写库不绕过服务层——与 `AuthIntegrationTest` 边界测试同做法）：

| 测试 | 覆盖的 DoD |
| --- | --- |
| `requestReset_forRegisteredEmail_returns200AndCreates6DigitCodeExpiringIn10Minutes` | DoD-1：200 + 恰新增 1 条记录 + `code` 匹配 `\d{6}` + `expiresAt` ≈ `clock.now()+10min`（固定时钟断言，容差 2 秒）；并断言**响应体不含验证码** |
| `requestReset_forUnregisteredEmail_returnsSame200BodyWithoutCreatingRecordOrSendingMail` | DoD-2：200 + 记录数不变 + `verify(emailSender, never()).send(...)`；并断言响应体结构与已注册场景完全一致（仅 `message` 键、值 = `RESET_MESSAGE`） |
| `requestReset_forRegisteredEmail_sendsEmailToRecipientWith6DigitCodeInBody` | DoD-3：`verify(emailSender).send(eq(email), anyString(), body-contains-DB中验证码)`——用 mock 参数验证，不解析日志 |
| `requestReset_blankEmail_returns200AndDoesNothing` | 附加边界：空白邮箱 → 200 + 不动作（防 NPE/脏数据） |

**既有 36 个测试**：全部仍通过（总 40/40），`User` record 加字段未破坏任何既有断言。✅
